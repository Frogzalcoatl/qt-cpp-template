# QT 6 C++ Template
Template project for the [QT 6 Framework](https://doc.qt.io/) with C++17. This template is designed to be IDE and compiler agnostic on Windows, MacOS, and Linux, but was specifically created with Windows and MSVC in mind.

## Prerequisites
1. **C++ Compiler:**
    * **Windows:** Included with QT 6 installer below
    * **Linux:** GCC or Clang (``sudo apt install build-essential libgl1-mesa-dev`` on Ubuntu/Debian)
    * **MacOS:** Apple Clang (``xcode-select --install``)
2. **QT 6 Framework:** [Download](https://www.qt.io/development/download-qt-installer-oss)

## Qt Creator
This project can be opened from the CMakeLists.txt file. Learn more about using QT Creator [here](https://doc.qt.io/qtcreator/).
